# Telegram Welcome Bot

بوت بلغة PHP لإرسال رسالة ترحيب تلقائية لمقدمي طلبات الانضمام إلى القنوات الخاصة في Telegram، مع لوحة تحكم للأدمن من داخل البوت.

## المتطلبات
- PHP 8 أو أحدث
- خادم ويب يدعم تشغيل PHP (Apache/Nginx) أو استخدام `php -S`

## الإعداد
1. ضع ملف `index.php` ومجلد `data/` على خادم ويب.
2. قم بتعيين التوكن ومعرف الأدمن عبر متغيرات البيئة أو تعديل القيم داخل `index.php`:
   - `BOT_TOKEN`
   - `ADMIN_ID`
3. اضبط الـ **Webhook** للبوت ليشير إلى رابط `index.php` باستخدام الأمر:

```bash
curl -X POST "https://api.telegram.org/bot<token>/setWebhook" -d url=<URL_TO_INDEX>
```

## الاستخدام
- عند إرسال `/start` من قبل الأدمن، تظهر قائمة بالقنوات التي رُصدت في الإعدادات.
- يمكن تعديل رسالة الترحيب وإضافة أو حذف الأزرار من خلال القوائم التفاعلية.
- يتم حفظ الإعدادات في ملفات JSON داخل مجلد `data/`.
- تتكدس أزرار الترحيب تحت بعضها، ويظهر للأدمن زر `/start` ثابت في لوحة المفاتيح.

## التشغيل محليًا لاختبار البوت
```bash
php -S localhost:8080
```
ثم اضبط الـWebhook على `http://YOUR_IP:8080/index.php`.
